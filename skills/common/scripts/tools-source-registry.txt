# tools-source-registry.txt — Android 逆向工具项目 git 来源清单
# ---------------------------------------------------------------
# 供 install-tools.sh / install-tools.bat 读取，是"下载工具项目"的唯一事实来源。
# 格式（每行，| 分隔，不可包含 |）：
#   <目标目录名>|<git clone URL>|<简短说明>
#   以 # 开头的行为注释，被脚本忽略。
# 维护规则：新增/改源时在此追加或更新；目标目录名为 source-projects/ 下的目录名。
# 注意：URL 的仓库名可以与目标目录名不同（见 reverse-tool）。
#
# -- 非 git 分发的工具（不适用 clone，已内置在工作区）--
#   dex2jar       : 发布版 jar 分发（source-projects/dex2jar/ 已含 lib/*.jar + bin 脚本）
#   FixStackmaps  : 工作区自带单个 Java 源文件（source-projects/FixStackmaps/FixStackmaps.java）
#
