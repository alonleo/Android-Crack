# 去功能点阶段接口与验收

这是各 type 的 07/08 阶段共用参考。type workflow 保留阶段位置与注册表路由；本页集中维护工作内容，不提供另一套直接调用子脚本的入口。

## 07：ui-hide

1. 首步 `load-feature-checklist` 通过管理器读取 [YAML 清单](feature-removal-checklist.yaml)，按 type 和 enabled 过滤，输出条目快照、候选关键词与 SHA-256。Agent 阅读自动生成的 [去功能点清单](feature-removal-checklist.md)，结合 [功能分类](../strategy.md#2-功能分类) 收集候选点。
2. 分析入口节点、生成源、布局、目标方法、回调和核心依赖，按 [引擎说明](engine-notes.md) 选择实现。
3. 将保留原因或隐藏/桩化/移除方案写入 `hide-plan.yaml`，包含当前项目对象、资源位置、方法签名以及经核实的 RVA（适用时）。候选不存在可记录不适用，但阶段不可跳过。
4. 通过当前 type 注册表路由的子阶段脚本执行并整理 `hide-report.yaml`；检查实际修改与计划一致。脚本的 `hook_container`、`hook_method`、`hide_node` 等标签须以实际实现为准；移出屏幕不代表布局和可达性已解决。
5. 通过负责构建的脚本验证当前工程与 APK。不能仅凭退出码或计划文件非空判定完成。具体输出位置从当前 register/脚本解析，不照抄历史编号目录。

### 阶段中的清单维护

- 查询条目用管理脚本 `list`/`get`；发现可复用的新功能点、关键词或约束时，用 `add`/`update`；确需删除规则时用 `delete`。调用与字段格式见 [脚本说明](../scripts/README.md)。
- CRUD 修改 YAML 后自动同步 Markdown；非法字段、重复 ID/key、无效 type 或不合法布尔值会拒绝写入。建议临时停用时使用 `enabled: false`，保留稳定 ID。
- 共享规则与项目结论分开：项目不存在某入口不应删掉全局条目。使用 `--registry` 可维护项目副本，运行阶段时通过 `FEATURE_REMOVAL_CHECKLIST` 指向同一副本；默认读取 skill 内共享清单。
- 清单在首步读为快照，当前步骤后续使用相同版本；中途修改清单需重跑首步和扫描/计划。IL2CPP 计划保存清单路径、摘要和候选 ID，便于核对。
- 加载/校验失败直接阻断，不回退到内置关键词。匹配只产生候选，`review` 不自动执行隐藏。

## 08：ui-hide-device-verify

通过注册表路由的真机脚本完成安装、启动、进入目标页面、截图和应用存活采样，保存 `verify-report.md` 及截图。核查：

- 目标入口不可见、不可点击，旧跳转不能由其他入口触发。
- 按钮、标签和所属布局不留空块、遮挡、拉伸或失效导航。
- 冷启动、页面重入、语言切换后动态节点不复现。
- 离线情况下仍可进入核心玩法，受影响的关卡、奖励、存档和必要设置正常。
- 弹窗关闭后的状态和回调能继续推进，无循环弹窗、卡等待或崩溃。

无设备、设备离线或验收条件不足时，按 AGENTS.md 在项目 `status.yaml` 的 `current_stage`/`failed_stages` 记录该阶段和原因并暂停，不得以构建代替真机验收。通过后立即记录并固化经验/脚本。

## 弹窗与语言补充

评分、更新、通知、广告、订阅和引导弹窗分别检查触发、展示、状态完成三个环节。SDK 组件/权限清理见 [第三方 SDK skill](../../third-party-removal-strategy-skill/SKILL.md)。仅修改 public consent API 可能被 SDK 内部检查绕过，仍要追踪实际显示类；混淆类名和方法签名不可跨版本照搬。隐藏同意 UI 不等同于用户已同意数据收集；停用 SDK 时应同时停止相关初始化与采集。

语言白名单按项目要求和实际可用语言确定；未另行指定时默认简体中文与 English，不硬编码历史语言索引。语言菜单、国旗、Tab、生成数组和布局一起核查，目标语言必须仍可选且切换后可玩。
