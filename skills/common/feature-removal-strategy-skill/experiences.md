## 已固化经验

### Unity 动态菜单与语言列表需要合并修改生成源
- 分类：动态 UI
- 适用范围：Unity IL2CPP/Mono 的菜单页、语言页和组件列表生成按钮
- 触发现象：入口隐藏后在重入页面时复现，或后一次资源写回丢失前一次修改
- 根因：动态创建会覆盖单次节点隐藏；同一源资源的独立写回互相覆盖
- 解决方案：区分 MenuPage、普通布局按钮和动态 buttonList；同一源资源的关联修改合并应用
- 验证方式：反复进入目标页面、切换语言，入口不复现且布局正常
- 注意事项：不照抄其他项目的对象 ID 和语言索引
- 相关文档：[Unity 实现](references/engine-notes.md#il2cpp)

### 多场景标题或品牌资源需要覆盖所有加载入口
- 分类：资源/品牌 UI
- 适用范围：Unity BundleFile 中标题在加载页、主菜单等多个场景独立实例化
- 触发现象：修改一处后，另一个页面仍显示标题
- 根因：同一视觉元素存在多个场景实例，纹理替换也未必命中实际渲染路径
- 解决方案：建立场景与对象映射后统一处理，区分游戏资源和引擎闪屏配置
- 验证方式：冷启动、加载页和主菜单均无目标资源残留
- 注意事项：同名对象可能承担不同功能，先确认父子层级和用途
- 相关文档：[Unity 实现](references/engine-notes.md#il2cpp)

### Hook 新增隐藏判断时要补齐声明与安全分支
- 分类：native hook
- 适用范围：IL2CPP native bridge 中新增 UI 显隐判断
- 触发现象：native 构建失败，或运行时进入未定义分支
- 根因：调用新增判断函数时，声明、实现或默认返回路径未同步
- 解决方案：在当前工程实际 native 修改点同步声明、实现和安全默认分支
- 验证方式：构建通过，处理前后核心 UI 均可启动和访问
- 注意事项：函数地址和对象 ID 只写项目记录
- 相关文档：[Unity 实现](references/engine-notes.md#il2cpp)

### 仅隐藏一次渲染结果会被动态生成逻辑覆盖
- 分类：动态 UI
- 适用范围：按钮、Tab 或菜单项由列表、模板或生成函数重复构建的场景
- 触发现象：目标入口短暂消失，重新进入页面或刷新后又出现
- 根因：处理发生在渲染结果而非生成源，后续构建重新创建节点
- 解决方案：在 type workflow 指定的生成源、数据列表或安全入口处理，并复核关联布局
- 验证方式：反复进入目标页面后入口仍不可见，布局正常
- 注意事项：不得据此删除仍被核心流程使用的数据项
- 相关文档：`strategy.md`

### 移除入口前必须确认回调与核心状态解耦
- 分类：入口
- 适用范围：广告、商店、登录、同意或外链入口存在完成回调时
- 触发现象：入口隐藏后启动卡住、奖励不结算或菜单无法继续
- 根因：调用方依赖目标功能的成功、关闭或状态更新回调
- 解决方案：先识别回调与状态依赖，再由 type workflow 选择保留、桩化或移除
- 验证方式：受影响路径可重复完成且核心状态正确
- 注意事项：核心玩法相关的商店、奖励或存档入口必须保留
- 相关文档：`strategy.md`
