## 已固化经验

### 文本替换必须保持格式语义
- 分类：文本
- 适用范围：含变量、格式化占位符、富文本或控制序列的字符串
- 触发现象：替换后崩溃、变量未显示或 UI 文本错位
- 根因：翻译破坏了占位符、转义序列或标记结构
- 解决方案：翻译前后逐项保持非自然语言片段、参数顺序和标记配对不变，并由 type workflow 选择安全写入方式
- 验证方式：覆盖带变量和富文本的页面，确认显示与行为正确
- 注意事项：不能仅以静态文本页面通过作为结论
- 相关文档：`strategy.md`

### 字体加载成功不等于字符覆盖完整
- 分类：字体
- 适用范围：需要显示目标语言字符且可能经过 fallback 的界面
- 触发现象：字体文件存在或界面未报错，但仍出现缺字、替代字形、裁切或异常换行
- 根因：字体缺少所需字形，或 fallback 与字形度量在不同页面的表现不一致
- 解决方案：按实际显示字符集检查字形覆盖、fallback 结果及行高和字宽，并保持具体注入方式由 type workflow 决定
- 验证方式：在启动、菜单、核心玩法和关键弹窗中确认中文可读且无缺字、重叠或截断
- 注意事项：不能以字体文件存在、单页显示或单个字符正常代替覆盖结论
- 相关文档：`strategy.md`

### 图片文字替换必须保持资源显示契约
- 分类：图片
- 适用范围：含可见文字且需要替换或重绘的图片资源
- 触发现象：中文文字可见但图片失真、透明异常、比例变化或布局错位
- 根因：替换结果改变了原资源的格式、尺寸、透明信息、压缩特性或引用预期
- 解决方案：以原资源的显示契约为边界重绘和替换，保持格式与几何信息，并复验文字可读性和布局
- 验证方式：在实际页面确认图片中文字可读，且没有变形、拉伸、黑边、透明异常或布局变化
- 注意事项：具体图片容器、资源目录和引擎格式属于 type workflow
- 相关文档：`strategy.md`

### 动态 UI 的语言文本不能只验证单次页面
- 分类：验证
- 适用范围：列表、奖励、联网缓存或运行时脚本生成文本的界面
- 触发现象：初始页面正常，重新进入或状态变化后出现原文或乱码
- 根因：动态来源未被覆盖，或字体 fallback 只在部分路径生效
- 解决方案：按 type workflow 定位动态来源，并覆盖页面重建与状态变化路径
- 验证方式：重复进入页面并触发相关状态变化后仍显示正确
- 注意事项：类型专属动态机制写入对应 type `experiences.md`
- 相关文档：`strategy.md`
